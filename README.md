# Robothink Rostering

Weekly coach rostering for Robothink: venues, coach availability, auto-generated drafts and Excel export.

## Branches

- `main`: stable code.
- `front-end-ui`: admin dashboard and weekly roster UI (Vite + React + Tailwind).

## Run locally

```bash
npm install
npm run dev
```

Tests: `npm test`
